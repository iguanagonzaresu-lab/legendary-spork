# Screenshots and runtime evidence

Actually view the supplied image if a compatible viewer exists; otherwise state
that it was not visually inspected. An OCR transcript or user description is
secondhand evidence and cannot establish pixel size, color or position precisely.

Align the design and implementation by component, version, viewport, DPR/scale,
theme, locale, content, font loading and interaction state before comparing.
Unknown capture context can explain a discrepancy; do not silently resize a
reference and claim the resulting dimensions are design specifications.

Screenshots can support visible text or placement observations but cannot prove
backend behavior, keyboard operation, accessible names, offscreen content or
hidden UI states. Never infer an item's absence outside the captured region.
Exact differences need measurements; estimates must be labeled as estimates.

When approved browser inspection is available, collect bounding boxes, relevant
computed styles, viewport, active state and screenshot evidence together. Use
read-only observations; do not submit real forms, make purchases or change user
data to exercise a state. A running local preview may be used when in scope;
starting services or executing project scripts may require separate permission.

Pixel differences can corroborate a finding, not establish its cause. Font
rasterization, compression and capture environment can cause non-regression
differences. Do not claim a specific component/source file caused a screenshot
change without matching source evidence. Figma API/Playwright automation and
image-diff computation are not bundled capabilities of this v0.1 Skill.
